## Launch checklist (v1.0)
1. Upload `Ma_Lakshmir_Puja_v25.pdf` to Google Drive, Share > Anyone with the link > Viewer. Name: "Ma Lakshmir Puja - Sahaj Poddhoti o Panchali (v1.0).pdf".
2. Test the link in a private/incognito window on phone and laptop.
3. Create the GitHub repo, add the 3 files, create Release `v1.0` with the PDF attached, notes from `release_notes_v1.0.md`.
4. Test the release download in a private window.
5. Post on LinkedIn: Drive link in first comment (or upload PDF as a document); GitHub release as backup link.
6. Keep a note of the exact file shared (checksum below).
